## Project Overview

- **Language(s):** Rust 2024 edition
- **Framework(s):** tokio (async runtime), clap (CLI)
- **Package Manager:** cargo (workspace)
- **Architecture:** Client-server over Unix domain sockets. `pk-cli` (CLI frontend) communicates with `pk-daemon` (background daemon) via bincode-serialized IPC. `pk-core` is the shared library.

## Architectural Decisions (Existing)

- DEK/KEK hierarchy: random DEK encrypts age key, two KEKs (passkey + password) each encrypt the DEK
- XChaCha20-Poly1305 for all symmetric encryption (side-channel resistant)
- `secrecy` + `zeroize` for memory-safe secret handling
- 15-minute TTL for unlocked state with automatic locking
- `execvp` process replacement for sops execution (no memory residual)
- bincode serialization for IPC protocol with length-prefixed framing
